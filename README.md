# SubVideoPlayer 一款基于Qt5的音视频播放器

SubVideoPlayer 是一款基于 **Qt5** 开发的 Windows 桌面音视频播放器。该软件集成了媒体播放核心与完善的后台管理系统，为用户提供了一站式的视听及会员服务体验。
---

## 🏘️ 最新版本

https://github.com/huizhang557/subvideoplayer/releases

## 🚀 核心功能

* **音视频播放**：高性能的媒体播放引擎，支持多种主流格式切换与播放控制。

    * `选择播放文件`

    * `基本播放控制（播放、暂停、上一个、下一个等）`

    * `倍速播放（0.5x\0.75x\1.0x\2.0x`

    * `图像基本设置(饱和度，灰度等)`

    * `弹幕，视频截图等`



* **用户信息管理**：完善的登录与注册系统，支持用户个人资料的修改与安全管理。

    * `用户注册`

    * `用户登录`

    * `密码找回`

    * `设置和修改用户基本信息`



* **视频资源管理**：对视频库进行分类、检索与维护，方便高效管理媒体资源。

    * `用户自定义视频合集`

    * `自定义视频分类`

    * `上传视频`

    * `删除，下载视频`



* **会员管理系统**：集成会员等级与权限校验逻辑，支持针对特定用户的会员功能分发。

    * `会员购买以及会员功能`



* **自定义浏览器**：内嵌qwebengines模块，实现浏览器基本功能，可进行文件下载。

    * `基本浏览器功能`

    * `前进，后退，刷新，收藏`

    * `历史记录`

    * `文件下载等`


## 🛠 技术栈

* **开发框架**：Qt5 (C++)

* **运行平台**：Windows

* **核心模块**：

    * `Qt Multimedia`：负责多媒体流的处理。

    * `Qt Widgets`：构建流畅的图形用户界面。

    * `Qt SQL`：用于本地用户数据及视频信息的持久化存储。



## ⚙️ 环境要求

* **操作系统**：Windows 10/11

* **编译环境**：Qt 5.12.0 且配置有 `MSVC2017_64` 编译环境。

* **依赖**：确保系统中已安装相应的解码器插件（如 **K-Lite Codec Pack**）以获得最佳兼容性。


## 🔧 如何构建

1.  **克隆项目**：克隆或下载本项目仓库到本地。

2.  **打开项目**：使用 Qt 5.12.0 打开项目配置文件 `subvideoplyer.pro`。

3.  **配置 Kit**：根据您的编译器环境选择对应的 **MSVC2017_64** Kit。

4.  **编译运行**：执行 `Run` (快捷键 `Ctrl+R`) 即可完成编译并启动程序。
